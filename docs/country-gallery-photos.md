# Country gallery photograph attribution

These 14 photographs are for the illustrative `/path` country gallery, not a
claim about a university, campus, course or intake. Locations and authors were
checked against each Wikimedia Commons file record (image description, author
and machine-readable license), then the images were visually inspected. The
`960px` Commons JPEG thumbnails were converted into same-dimension WebP files
at quality 85. No file was cropped; the gallery frames crop them **visually**
with `object-fit: cover`. The WebP adaptations remain available under the
respective photograph's original Creative Commons license (including ShareAlike
where marked). Attribution, source and license are also linked beside the
currently visible photograph in the UI. These licenses apply to the photographs,
not the remainder of Waymark's code or design.

The existing homepage US image is a **Chicago** scene despite having been called
“New York.” The “156 LaSalle” bus matches the [Chicago Transit Authority's
route](https://www.transitchicago.com/bus/156/); the building at the end of
LaSalle Street matches the [Chicago Architecture Center's identification of
the Board of Trade Building](https://www.architecture.org/online-resources/buildings-of-chicago/chicago-board-of-trade-building).
The alt text, internal city label and approximate latitude (41.88° N, matching
the [41.8778° N Board of Trade location](https://topoquest.com/place/illinois/building/chicago-board-of-trade/1826553))
were corrected. Its photographer-supplied Unsplash location metadata could not
be checked because its individual photo
page was unavailable; this is a visual/landmark identification, not a source
metadata claim. The homepage remote image itself is unchanged.
